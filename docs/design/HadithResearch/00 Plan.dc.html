For specialist review (26–32, drafts built)
  • Matn alignment: default normalization levels, and the names for addition, omission and substitution. A difference is never labelled a defect.
  • Isnād graph: how far traversal goes by default, which transmission formulas appear on edges, and how missing links are drawn so nothing invents an intermediary.
  • Hadith families: the relationship types for shawāhid and mutābaʿāt, and how algorithmic candidates are labelled apart from reviewed members.
  • ʿIlal cases: the list of discrepancy categories, and wording for “inconclusive” so no authenticity verdict is forced.
  • Narrator dossier: wording for impossible / possible / documented meeting / documented audition, and how a teacher-specific judgment is shown.
  • Book structure and terminology: which critic expressions are counted, and the unit for each count.
  • Argument map: the relationship set (objection, reply, qualification, alternative conclusion) and anything missing from it.

Decisions recorded

Desktop only
Research work needs a large screen, so there are no phone layouts. The researcher, editorial and admin workspaces target 1024px and wider. Narrower windows get a notice asking for a larger screen instead of a squeezed layout. This replaces the 360px rule in conventions.md §8 (NFR-12), so update that spec. Public pages (announcements, publications, search) still read acceptably on a tablet. Comparison views may still scroll sideways inside a labelled area.

Still open (outside design)

  • Sorani and Arabic UI labels: terminology.md has no entries yet, so screens use English for review.
  • Sample hadith texts, chains and critic judgments are illustrative fixtures. They need specialist review before testing.
  • The exact definition of an “occurrence” depends on DATA-02 (R0).
  • Limits shown (1 GB parts, 5,000-member result sets, 5 GB quota, 7-day support grants) are placeholders until the R0 workload benchmark.
