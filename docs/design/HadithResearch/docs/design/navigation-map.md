| UC-07 Download all research | 12 Downloads → scope preview → job → download part; regenerate when expired |
| Onboarding | 01 Registration → verification → approval (13 Administration) → 02 Home |
| Collaborate | 15 Members (invite) → 16 Discussion & tasks → 17 Notifications → 18 Activity |
| Announce | 11 Finding → 19 Announcement editor (public preview) → 20 Public announcement → 40 Collaboration interest → 15 Members |
| Publish | 11 Finding → 21 Submission → 22 Editorial console → 23 Reviewer workspace → 22 Release → 24 Public publication |
| Deep analysis (R2) | 10 Comparison → 26 Matn alignment / 27 Isnād graph / 30 Narrator dossier → 29 ʿIlal case → 32 Argument map → 11 Finding |
| Datasets (R2) | 08 Search → 33 Dataset builder → 38 Export → 39 Public dataset page |
